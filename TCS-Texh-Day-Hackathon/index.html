SEO Keyword Injection Protocol

Ensures high search visibility without keyword stuffing penalties

  • Primary Keyword: Must appear in the Product Title and within the first 60 words of the body text.
  • Secondary Long-Tail Keywords: Distributed naturally across the Amazon 5-point bullets and the Google SERP meta description.
  • Search Intent Matching: Automatically appends commercial and transactional query modifiers (e.g. best price, specifications, buy online).
  • Density Guardrail: Keyword density strictly kept between 1.5% and 2.8% to avoid Google Panda penalties.

Architecture, Data Formats & API Specs

Technical documentation covering data consideration, prompt engineering pipeline, and Spring Boot REST integration.

1. Solution Overview & Problem Context

Retailers face a critical bottleneck when adding thousands of new catalog items regularly: manual copywriting is expensive and prone to inconsistent tone, while rigid templates produce sterile, unengaging product listings.

CatalogCraft AI solves this with a domain-adapted Generative AI architecture that converts structured tabular product attributes into compelling, multi-channel product copy with guaranteed SEO keyword inclusion and 85%+ creative relevance.

2. Structured Input Schema (CSV / JSON)

The system accepts structured datasets conforming to the following specification:

{
  "id": 1,
  "name": "AuraWave ANC Wireless Headphones",
  "category": "Electronics",
  "price": 2999,
  "currency": "INR",
  "features": [
    "Bluetooth 5.3",
    "40-Hour Battery",
    "Active Noise Cancellation",
    "Memory Foam Earcups"
  ],
  "keywords": [
    "wireless headphones",
    "noise cancelling"
  ],
  "tone": "Sophisticated & Luxury",
  "target_audience": "Daily Commuters & Audio Enthusiasts"
}

3. Spring Boot Backend REST API Contracts

The frontend is architected to seamlessly connect with a Spring Boot or FastAPI backend:

POST /api/products/generate

Generates multi-format description for a single product attribute payload.

POST /api/products/batch

Streams or batch-processes array of up to 500 product attributes.

GET /api/health

Health check endpoint reporting GenAI model status and latency.

4. Prompt Engineering & Conditioning Methodology

Rather than generic zero-shot prompts, the generator employs domain-adapted few-shot conditioning:

  1. Attribute Canonicalization: Validates presence of price, features, and target keywords.
  2. Tone Conditioning: Injects persona-specific vocabulary restraints and opening hooks.
  3. Constraint Injection: Enforces marketplace bullet formatting, 155-character meta limits, and cliché bans.
  4. Deterministic Post-Processing: Computes Flesch-Kincaid readability, keyword presence checklist, and Schema.org JSON-LD generation.
